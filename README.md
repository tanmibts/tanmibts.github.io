# tanmibts.github.io

Personal website built with React and published on GitHub Pages.

---

## 🚀 Deployed Branch (Live Website)

- **Live Deployed Branch:** **`gh-pages`**
- **Public URL:** [https://tanmibts.github.io/](https://tanmibts.github.io/)

> **Note:** GitHub Pages is configured to serve the **`gh-pages`** branch. Whenever you run `yarn deploy`, Create React App compiles your source code and publishes the static build directly to **`gh-pages`**.

---

## 🌿 Branch Structure

- **`add-img-blob` Branch:** Active feature development branch (branched off `deploy`). **Work on this branch!**
- **`deploy` Branch:** Main source code branch.
- **`gh-pages` Branch:** Contains the compiled static HTML/CSS/JS build generated by `yarn deploy`. **GitHub Pages serves this branch live.**
- **`master` Branch:** Legacy branch (do not use for active development).

## 🛠️ Developing Locally from Scratch

### 1. Prerequisites (macOS Setup)

If `npm` or `yarn` are not yet installed in your terminal:

```bash
# 1. Add Homebrew to your PATH (if installed via Homebrew)
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zshrc
eval "$(/usr/local/bin/brew shellenv)"

# 2. Install Node.js (includes npm)
brew install node

# 3. Enable yarn
corepack enable
```

---

### 2. Local Development (React Source Code)

1. **Check out the active feature branch (`add-img-blob`):**
   ```bash
   git checkout add-img-blob
   ```

2. **Install dependencies:**
   ```bash
   yarn install
   # or: npm install
   ```

3. **Start the development server with live reload:**
   ```bash
   yarn start
   # or: npm start
   ```
   Open **[http://localhost:3000](http://localhost:3000)** in your browser.

---

### 3. Deploying Updates to the Live Site

When you are happy with your local changes on `add-img-blob`:

1. **Commit your changes:**
   ```bash
   git add .
   git commit -m "Add image blob feature"
   git push origin add-img-blob
   ```

2. **Deploy to GitHub Pages (`gh-pages` branch):**
   ```bash
   yarn deploy
   # or: npm run deploy
   yarn global add serve
   serve -s build
   ```
   *This automatically builds your React app and pushes the compiled production output to the `gh-pages` branch, updating https://tanmibts.github.io/.*

---

### 4. Previewing the Live Production Build Locally

To test the exact static production files compiled on the `gh-pages` branch locally:

```bash
git checkout gh-pages
python3 -m http.server 8000
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser.
*(Remember to switch back to `git checkout add-img-blob` when editing code again!)*

## 🖥️ Customizing & Saving Desktop Icon Initial Positions

The main page features draggable folder icons. To set a new default initial layout for the folders:

1. **Arrange the icons** on `http://localhost:3000/#/` by dragging them to your desired desktop layout.
2. **Extract current coordinates** by opening Developer Tools (`Cmd` + `Option` + `I` on Mac) > **Console** tab and running:
   ```javascript
   Array.from(document.querySelectorAll('.draggable-folder')).map(el => {
     const parentWidth = el.parentElement.clientWidth;
     const match = el.style.transform.match(/translate3d\(([^px]+)px,\s*([^px]+)px/);
     const xPx = match ? parseFloat(match[1]) : 0;
     const yPx = match ? parseFloat(match[2]) : 0;
     return {
       folder: el.innerText.replace('::', '').trim(),
       xPct: Math.round((xPx / parentWidth) * 100),
       y: Math.round(yPx)
     };
   })
   ```
3. **Update [`src/Projects/Projects.tsx`](file:///Users/vtan/code/tanmibts.github.io/src/Projects/Projects.tsx)**: Update the `initialPosPct={{ xPct, y }}` values inside `<Projects />` with the extracted `{ xPct, y }` coordinates.
